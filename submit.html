投稿说明

  • 点「提交投稿」→ 新标签打开 GitHub 新建 Issue（内容已填好）→ 点「Submit new issue」确认，投稿即变成仓库里的一个 Issue。
  • 没有 GitHub / 打不开 GitHub：点「复制全部内容」，把内容粘贴发给我（QQ/邮箱），我帮你发布。
  • 站主会审阅；通过后再手动发布到网站。
