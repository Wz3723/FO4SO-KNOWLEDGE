投稿攻略

填好内容后点「提交投稿」，会帮你在 GitHub 打开一个**已填好内容的新 Issue**，你再点一次确认即可完成投稿。

排版好的短文/攻略最容易通过；图片最好用可公开访问的链接。

投稿说明

  • 点「提交投稿」后会在新标签页打开 GitHub 的"新建 Issue"，内容已自动填好。
  • 你在 GitHub 上点一次「Submit new issue」确认，投稿就变成仓库里的一个 Issue。
  • 站主会看到并审阅这份投稿；通过后再手动发布到网站。
需要一个 GitHub 账号；若打不开 GitHub，可把内容通过"联系方式"联系站主。
